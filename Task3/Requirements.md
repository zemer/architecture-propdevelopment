# Список требований для внешней интеграции умного дома

## Требования к безопасности

1. Данные должны передаваться по протоколу TLS 1.2+ для предотвращения перехвата, подмены или подделки информации.
2. Хранимые данные должны быть обезличены, чтобы исключить прямую связь клиентов, биометрии и номеров автомобилей.
3. Доступ только авторизированным пользователям и устройствам.
4. Логирование вызовов API и действий пользователя для возможности аудита.

## Протоколы аутентификации и авторизации

1. Двухфакторная авторизация для доступа в мобильное приложение.
2. Протокол взаимодействия OAuth 2.0.
3. Ролевая модель для доступа к информации и устройствам.

## Взаимодействие между системами предприятия и внешней платформой

1. Сервисы внешнего провайдена взаимодействуют через API Gateway, в котором реализуется Rate limiter и проверка авторизации.
2. Перед API Gateway должен быть установлен Firewall для предотвращения DDOS атак.
3. Мониторинг сетевой активности для быстрого обнаружения и оперативной реакции на аномальные потоки данных
